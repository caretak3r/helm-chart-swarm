# certificates fixtures

Test-only TLS material for chart-test-swarm certificate scenarios.
These keys/certs are intentionally short-lived and used ONLY for
local kind cluster testing. They are never used in production.

## Files

- `selfsigned-clusterissuer.yaml` — ClusterIssuer (selfSigned) used by
  self-signed-ca and wildcard scenarios.
- `letsencrypt-staging-clusterissuer.yaml` — ClusterIssuer (ACME) targeting
  the Let's Encrypt staging endpoint. The private key is generated by
  cert-manager at runtime.

## Security note

Fixtures in this directory are committed intentionally for reproducibility.
No production CA keys or certificates live here. The `selfSigned` issuer
generates its own key pair at runtime — there are no static private keys
in this directory.
